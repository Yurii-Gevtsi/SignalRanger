# Reference Consultation: Character Archetypes

Feature:
: 2-3 оригінальні character archetypes для варіативності юнітів у бою (пункт Definition Of MVP).

Example signals:
: Приклади показують, що юніти/класи зазвичай відрізняються здоров'ям, розміром, спеціальними здібностями й роллю в загоні, а прогресія часто вводить міцніших ворогів пізніше. Для MVP корисний принцип — легкий data-template юніта (насамперед здоров'я й читабельний силует), а не повна система класів зі здібностями.

Useful principles:
: Архетип — це проста data-сутність (id, назва, здоров'я, висота тіла), відокремлена від бойової логіки. Варіювати супротивника за складністю місії дає відчутну прогресію без нових систем. Силует має читатись з першого погляду.

Risks to avoid:
: Не копіювати чужі класи, назви, статистики, здібності чи art. Не додавати складні здібності/пасивки, доки базовий бій не стабільний. Не робити перевагу за рахунок платних архетипів.

Our original implementation:
: `CharacterArchetype` (чиста data) + `PrototypeArchetypeLibrary` із трьома архетипами — `Штурмовик` (100 HP, базовий), `Розвідник` (80 HP, крихкий), `Бастіон` (135 HP, міцний). Гравець завжди фіелдить `Штурмовика`; супротивник обирається за складністю місії (`ForDifficulty`: easy→Розвідник, normal→Штурмовик, hard→Бастіон). Бій бере з архетипу max health і висоту тіла (силует). Покрито edit-mode тестом валідності й масштабування здоров'я за складністю.
