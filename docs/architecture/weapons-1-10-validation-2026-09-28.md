# Перевірка зброї №1–10

Дата: 2026-09-28. Статус `implemented` у каталозі означає реалізовану й перевірену бойову механіку. Після уточнення власника від 2026-09-28 **числовий баланс шкоди всіх атакувальних одиниць ще не закрито**: відсутні `H_cap(1…60)`, відсотки кожного кроку ядра й запис рівня/абсолютної дельти покупки. ## Наступна необхідна робота для повного числового закриття

1. Задати глобальну криву `H_cap(L)` для рівнів 1–60: верхній корпусний HP з усіма дозволеними на рівні моделями та постійними HP-покращеннями, однаковий поріг для кожного гравця; тимчасовий щит окремо.
2. Для кожної зброї задати стартовий відсоток `p(w)` і для кожної покупки ядра відсоток `q(w,i)`. Обчислити й зафіксувати `BaseDamage` на рівні відкриття та `CoreDelta` на рівні фактичної покупки.
3. Зберігати абсолютну дельту або рівень покупки в сейві, визначити міграцію старих записів і показувати ті самі числа в UI та симуляції.
4. Окремо виправити два виявлені тести балки й мортири, коли дійдемо до їхнього пакета.
