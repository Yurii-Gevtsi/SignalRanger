# Вирівнювання поведінки зброї за референсом

Статус: реалізовано (2026-07-23).
Область: `BattleSimulation` — постріли, вибухи, відскоки, таймери зброї.

## Контекст

Ручний плейтест показав, що частина бойових механік «не гладка»: дивні
відскоки гранати, граната, що довго лежить без вибуху, «п'яні» траєкторії
самонавідної ракети, вогнемет, що зливає весь струмінь в одну точку, і
кілька сценаріїв зависання ходу. Порівняли кожен тип зброї з перевіреним
у продакшені референсом жанру і вирівняли *принципи* (не константи й не
код) там, де наша реалізація розходилась.

## Знайдені розбіжності та рішення

| Система | Було | Стало (принцип референсу) |
|---|---|---|
| Точка вибуху | резолв усередині ґрунту | остання вільна точка перед контактом — вирва кусає поверхню, радіальний урон не гаситься |
| Відскік (граната/телепорт) | вісь відбиття вгадувалась за домінантною компонентою швидкості | семплінг сторін контакту (left/right/top/bottom), інверсія dx і dy незалежно; fallback на стару евристику для кутів |
| Фітіль гранати | 3 с *після* зупинки (разом до 11 с) | таймер іде від кидка (`TimeoutSeconds` = фітіль, 4.5 с); у спокої дотікає залишок |
| Бластер-черга | якщо патронів < 3 — хід не завершувався (для бота — вічне зависання) | хід завершується на 3-му пострілі, при порожньому магазині або одразу для бота |
| Міна | дія не витрачалась → друга атака в той самий хід; бот не завершував хід; trigger 3 с | міна = атака ходу: повторний `TryFire` заблоковано, гравцю лишається вікно відходу 5 с, бот віддає хід одразу; arm 2 с, trigger 1 с |
| C4 + таймер ходу | таймер міг спливти під час фітіля → хід переходив боту, а `TryFire` бота блокувався pending-зарядом → deadlock | таймер ходу гравця стоїть, поки горить фітіль |
| Самонавідна ракета | наведення з першого кадру + постійна гравітація | фаза вільного польоту 0.45 с з гравітацією → далі політ без гравітації зі сталою швидкістю, поворот 210°/с |
| Осколки мортири | 3 фіксовані напрямки вгору | 5 осколків віялом ±45° навколо реверсу вектора падіння (детерміновано, без RNG — важливо для реплеїв) |
| Бур-ракета | напрямок у тунелі залочений, гравітація вимкнена | сили діють і в ґрунті — тунелі вигнуті; тунель ширший (0.24) |
| Вогнемет | усі блоби з однією швидкістю → вогонь в одну точку | швидкість блоба росте по черзі (×0.65→×1.35), кут флуктуює ±2.5° — вогонь лягає доріжкою |

## Інваріанти, які захищаємо тестами

- Хід не може зависнути: будь-який постріл будь-якою зброєю будь-якої
  команди завершується передачею ходу або явним retreat-вікном.
- Одна атака за хід: міна/C4 блокують повторний постріл.
- Детермінізм симуляції: жодного `UnityEngine.Random` у
  `BattleSimulation`; веєра осколків і джиттер вогню — функції індексу.

Тести: `BattleSimulationTests` — `Grenade_FuseCountsFromThrow_*`,
`Blaster_OutOfAmmoMidBurst_*`, `Mine_BlocksSecondAttackInSameTurn_*`,
`Mortar_MainImpact_SpawnsFiveHalfStrengthFragments`.
