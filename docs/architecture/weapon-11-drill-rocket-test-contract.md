# Контракт перевірки бурової ракети №11

Дата: 2026-09-28. Джерело: `docs/design/weapon-combat-specification.md`, картка 11, і `docs/design/weapon-catalog-canonical.md`, §3.4.

Поточні відхилення: ракета має змінну швидкість 5–13 замість спільних 12, радіус вибуху 1.25 замість спільних 1.55, базово бурить лише `Soil`, а старі гілки еволюції змінюють матеріал/час замість погодженого ТТХ «Радіус». Наявний корпус `bur_rocket` і прозорий хвіст `missle_tail_clean` уже збираються в одне сценове дерево.

Поведінкове приймання: постріл із будь-яким введеним значенням сили має швидкість `V0=12`; ракета стирає всі руйнівні текстури `Soil`, `LightMetal` і `Titanium`, не витрачає запас пробивання в повітрі, після сумарної однієї секунди всередині перешкод вибухає. Кожна з чотирьох покупок ТТХ «Радіус» додає 10% до часу/еквівалентної довжини пробивання; радіус вибуху від цього не росте. Для різних покупок в UI і runtime має бути однакове значення. У PlayMode снаряд має правильний корпус і дочірній хвіст, які разом рухаються й повертаються. Прототипна абсолютна шкода лишається сталою для цілей із різним HP до введення загальної `H_cap`.

Власники змін: `PrototypeWeaponLibrary` — стартові параметри, `WeaponUpgradeChoiceResolver` — ТТХ, `BattleSimulation` — моментальна конфігурація проникнення та колізії, `BattleSceneController` — тільки за потреби для сценового скіна. Перевірка через публічну симуляцію, ресурсні тести та реальну бойову сцену.
