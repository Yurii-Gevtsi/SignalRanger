# Локалізація

## Джерело перекладів

Для кожної мови існує один UTF-8 JSON-словник у
`Assets/_Game/Content/Resources/Localization/`:

```text
uk.json
en.json
pl.json
de.json
es.json
fr.json
it.json
pt-BR.json
ja.json
ko.json
tr.json
ar.json
zh-Hans.json
```

JSON групує рядки за контекстом (`ui`, `intro`, `battle`, `content`), а
код звертається до стабільних ключів з крапкою: `ui.play`,
`intro.sigma.body`, `battle.ammo`.

Додати мову означає скопіювати `uk.json`, назвати файл кодом локалі
(`pl.json`, `de.json`) і перекласти тільки значення. Ключі не можна
видаляти або перейменовувати без зміни коду.

## Runtime

`JsonLocalizationService` завантажує словники через Resources, зберігає
вибраний код мови у `SaveSettingsData.languageCode` і використовує `uk`
як fallback, якщо переклад або мова ще відсутні.

Для параметризованих рядків використовуються іменовані маркери:

```json
"ammo": "Боєприпаси: {count}"
```

```csharp
AppServices.Localization.Translate("battle.ammo", new LocalizationArgument("count", 3));
```

## Правило: жодного хардкоду гравцеського тексту

**Жоден рядок, який бачить гравець, не повинен існувати як буквальний
літерал у C#-коді — ні в новому коді, ні в існуючому.** Єдиний
легітимний рядок-літерал у коді — це fallback-параметр виклику
`GameText`/`T(...)`: він показується, коли ключа ще немає в словнику
(`LocalizationRuntime.Get` повертає саме цей fallback), а не окрема
захардкоджена гілка виводу.

Це правило без винятків для «старого коду». Раніше воно було сформульоване
як «нові екрани не повинні» з приміткою «`GameText` переноситься
поступово» — саме ця м'якість дозволила `WeaponUpgradePresentation.cs`
накопичити 85+ захардкоджених українських рядків (назви й описи
модернізацій зброї, назви параметрів), які завжди показувались
українською незалежно від мови гравця, непомічені, доки їх не знайшли
руками. Виправлено 2026-08-15: усі рядки тепер проходять через
`GameText.WeaponEvolutionDescription`/`UpgradeStatName`/`UpgradeTitle*` з
відповідними ключами в `content.weaponEvolutionDescription`,
`content.upgradeStat`, `content.upgradeTitle`, `content.upgradeDescription`.

Перевірка перед тим, як вважати роботу з гравцеським текстом завершеною:

- Кожен рядок, повернений методом, що формує UI-текст, походить із
  виклику `GameText.*` або `AppServices.Localization.Translate(...)`, а
  не з `return "..."`, `$"..."`, `switch { ... => "текст" }` напряму.
  `switch`/`if` можуть будувати **fallback**-значення, яке потім
  передається в `T(...)` — але сама фінальна повернена гравцю string
  завжди йде через виклик локалізації.
- Новий текстовий контент (нова зброя, нова механіка, новий екран)
  одразу отримує ключ і значення щонайменше в `uk.json` та `en.json`;
  решта мов синхронізуються найближчим часом, а не залишаються порожніми
  на невизначений термін.
- Перед комітом, що додає чи змінює гравцеський текст, зроби швидкий
  grep на рядкові літерали українською/англійською в змінених C#-файлах
  поза межами `GameText.cs`/`LocalizationRuntime.cs` — знайдений літерал
  означає пропущений випадок, а не виняток.
