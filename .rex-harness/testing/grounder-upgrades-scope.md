# Grounder TTH upgrade scope

User goal: the grounder has four Core purchases, each extending duration by one opposing turn, and four Radius purchases, each adding 10% of base N0. Catalog must permit the Core path. Non-goals: balance of HP, projectile classification, skin, and generic upgrade behavior of other weapons. Public seams: saved `SaveWeaponProgressData` choices through `BattleWeaponProgression.FromResolver`, `WeaponProgressionCatalog`, `WeaponUpgradeChoiceResolver`, and battle events/physical projectile tests. Assertions: catalog Core limit is four; Core rank purchases produce two through six opposing turns; Radius purchase count gives exactly 1.0 through 1.4 times base detection radius and changes actual interception boundary. The smallest independent failing slice is catalog Core limit; the battle tests additionally prove purchased duration and radius affect combat. Completion requires Unity EditMode tests. Never weaken assertions or make the feature test-only.
