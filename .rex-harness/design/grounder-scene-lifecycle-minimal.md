# Grounder scene visual reuse decision

The visual is required because the existing simulation emits `GrounderDeployed` and `GrounderRemoved`, but `BattleSceneController` does not subscribe to either, so a placed device is invisible. Reuse ladder: (1) no accidental complexity to remove; (2) reuse `OnSimulationMineDeployed`'s GameObject/SpriteRenderer pattern, `_arenaObjects`, and `LoadWeaponIconSprite`, plus the existing `UI/Weapons/grounder.png`; (3) Unity SpriteRenderer and Destroy already cover the platform behavior; (4) no package dependency needed; (5) a local handler and dictionary are readable; (6) only new structure is a keyed dictionary for deterministic removal by device ID. Rejected: using generic projectile visuals because the grounder is placed without a projectile; using mine events because that would conflate two device lifecycles. Existing `GrounderDeployedEvent` already contains position and weapon. Target: `Assets/_Game/Runtime/Gameplay/Battle/Assembly/BattleSceneController.cs`.
